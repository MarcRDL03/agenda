# Agenda

Agenda del día, hábitos, tareas y calendario. Se instala como app en el móvil y en el PC y funciona sin conexión.

Aquí solo está la aplicación. Los datos se guardan en cada dispositivo y, si se conecta, en un repositorio privado aparte.
